# Tripster

Tripster is a full-stack hotel and property listing web application inspired by Airbnb. Users can explore property listings, view listing details, and share their experiences through reviews.

## Features

- Browse property listings
- Create, edit, and delete listings
- User authentication and authorization
- Upload listing images
- Add and delete reviews with star ratings
- Interactive maps for listing locations
- Responsive design for mobile, tablet, and desktop
- Flash messages for user feedback

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript, Bootstrap, EJS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas, Mongoose
- **Authentication:** Passport.js
- **Image Storage:** Cloudinary
- **Maps and Geocoding:** Mapbox
- **Deployment:** Render

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Arfaj2003/Tripster.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Tripster
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env` file and configure the required environment variables. Never commit your `.env` file or secret credentials.

5. Start the application using the command configured in your `package.json`.
